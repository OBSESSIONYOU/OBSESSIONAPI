# 防止数据和密钥误传

首次克隆后，在仓库根目录执行一次（Python 3.9+、Git）：

```powershell
python scripts/privacy_guard.py install
```

安装只写入本仓库的 Git 管理目录，自动下载固定版本、校验 SHA-256 的 Gitleaks。已有自定义钩子或 `core.hooksPath` 时会停止并保留原配置。新克隆需要重新安装；Git 不会自动启用仓库中的钩子。

- 提交前检查暂存区文件和密钥，不读取未暂存的同名文件代替暂存内容。
- 推送前检查实际待推送提交的全部可达历史，包括新分支、合并、重命名和脚本通过底层命令构造的提交。
- 本机扫描不联网；仅首次安装扫描器时访问 GitHub 官方发布下载地址。日志不显示密钥值。
- 环境文件、私钥、数据库、CSV、日志、压缩包、原始采集和模型文件默认被拦截。迁移目录中的 SQL 作为代码保留，仍接受密钥扫描。
- 已有演示数据按“路径 + 内容 SHA-256”登记在 `scripts/privacy-policy.json`，不会把整个目录加入免检名单；新样本或变化后的内容需要单独审查。
- SparkBox 专用策略可接受符合现有 AES-256-GCM 格式的加密备份；明文 SQL 仍被拦截。
- CI 在每次 push/PR 后复核。CI 属于上传后的检查，上传前主要依靠本机钩子及 GitHub 推送保护。

可手动复核全部当前历史：

```powershell
python scripts/privacy_guard.py ci
```

扫描器缺失、被替换、执行出错时会停止提交/推送。钩子可以被 Git 参数绕过，因此它用于防误操作，不能代替权限控制，也不能保证识别所有格式的敏感内容。请勿用跳过检查的方式提交真实密钥；发现真实泄露应先撤销或轮换凭据。
